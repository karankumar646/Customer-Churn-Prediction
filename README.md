# Telecom_Customer_Churn_Prediction


# Overview

This project predicts customer churn for a telecom company. It includes data loading, cleaning, visualization, and machine learning to identify customers likely to leave.

# Steps

* Loaded the data into PostgreSQL.
* Cleaned the data and created two views.
* Loaded the main data into Power BI and created the first visualization page.
* Exported the two views to Excel or CSV files.
* Loaded the exported data into Jupyter Notebook to build a prediction model.
* Saved the model output in a CSV file.
* Loaded the prediction results into Power BI to create the final visualization page.

# Tools Used

* PostgreSQL
* Power BI
* Python (Pandas, NumPy, Scikit-learn)
* Jupyter Notebook
* Excel / CSV
